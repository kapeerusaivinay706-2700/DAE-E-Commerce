# DAE E-Commerce

This repository contains an e-commerce data analysis and business insights project built using Jupyter Notebook.

## Project Overview
The project focuses on analyzing e-commerce order data to uncover patterns, trends, and insights related to sales performance, customer behavior, and operational metrics.

## Included Files
- `ECOMMERECE_PROJECT.ipynb` – main notebook with analysis and visualizations
- `E-Commerce_Orders_Data_Normal_PPT -1.pptx` – presentation slides
- `E-Commerce_Orders_Data_Normal_PPT -2.pptx` – additional presentation slides
- `dae report.pdf` – project report

## Language Composition
- Jupyter Notebook: 100%

## Notes
This repository is primarily notebook-based, with the analysis and reporting work centered around the main Jupyter project file.
